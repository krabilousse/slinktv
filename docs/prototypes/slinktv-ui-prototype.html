Design decisions & API boundaries

Guest discovery

Bundled channel picks, with no unverified live badges or viewer counts. Sign-in unlocks a live directory and search. Twitch Helix discovery needs a token; a Public Client ID alone is insufficient. Twitch API

Most viewers or Relevant

Viewer count is the default. Relevant uses only this account’s viewing on this TV: daily minutes, capped at 120 per channel, with a 14-day half-life and 90-day retention. Paused/buffering time does not count. Without history, fall back to viewers. This mockup starts with illustrative history.

TV focus and playback

Every action is reachable with the D-pad. Opening a channel starts at its best available quality. The first navigation/OK press reveals controls and focuses Pause; the next press acts. Back closes a quality menu, otherwise returns to the previous list and card. System volume remains system volume.

Local history, explicit controls

Relevant asks to use viewing history. Settings can stop collection or clear history. Sign-out clears this account’s local history. No Twitch-wide viewing history is available through Helix. No native telemetry or API changes are included in this HTML study.
